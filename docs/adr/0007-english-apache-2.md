# English for the repository; Apache-2.0 license

## Context and Problem Statement

The repository is public, a portfolio piece, and meant to be adoptable by companies.

## Decision Outcome

- English for code, comments, documentation and commit messages.
- License: Apache-2.0.

Rationale as recorded: portfolio reach and the open-source norm; Apache-2.0 is permissive,
includes a patent grant, and companies adopt it easily.

### Consequences

- Good, because the audience and the contributor pool are as wide as possible.
- Neutral: Apache-2.0 requires keeping the NOTICE file and stating changes in redistributed
  files.

### Confirmation

LICENSE and NOTICE at the root; SPDX identifiers in source files (ADR-0016).
